# Netflix Movies and TV Shows – Data Cleaning and Preparation

## Project Overview

This project focuses on cleaning, transforming, and preparing the Netflix Movies and TV Shows dataset using Python. The objective is to improve data quality, handle missing values, identify inconsistencies, and create a structured dataset suitable for further analysis.

## Dataset

- **Source:** [Netflix Movies and TV Shows – Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- **Original Records:** 8,807
- **Original Columns:** 12
- **Domain:** Movies and Television Shows

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Data Cleaning and Preparation Tasks

The following operations were performed:

1. Imported and explored the dataset.
2. Examined dataset structure, dimensions, and data types.
3. Identified missing values and calculated missing-value percentages.
4. Checked for duplicate records.
5. Handled missing values in relevant columns.
6. Standardized text values by removing leading and trailing whitespace.
7. Identified and corrected misplaced duration values.
